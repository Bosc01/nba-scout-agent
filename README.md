# NBA Scout Agent

AI-powered basketball scouting for college and international players.

## Problem
Small programs and international players get zero professional evaluation 
because scouting is expensive and human attention is finite. Data exists 
across the web — synthesis does not.

## What it does
Takes a player name, autonomously searches Basketball Reference, ESPN, 
and web sources, and produces a structured scouting report with NBA comp 
and confidence scores.

## Stack
Python, FastAPI, Claude API, React
